# Writeup’ы

Разборы распределяются по соревнованию и категории:

```text
writeups/
  2026-example-ctf/
    web/
      challenge-name.md
```

Перед публикацией убедитесь, что соревнование завершено или правила прямо разрешают публикацию решения.

> [!WARNING]
> Публиковать решения к занятиям разрешается
> только через неделю после самих занятий!
