# Занятие 08: задачи DownUnderCTF 2025

На занятии разбираются две web-задачи уровня `easy` из [публичного репозитория
DownUnderCTF 2025](https://github.com/DownUnderCTF/Challenges_2025_Public/tree/main).
Работа выполняется только с локально запущенными контейнерами задач.

## Задачи

### mini-me

Задача на анализ клиентской части веб-приложения. Нужно изучить ресурсы,
которые загружает фронтенд, и выяснить, какие данные не должны были попасть в
публичную сборку. Материалы задачи находятся в [`Tasks/mini_me`](Tasks/mini_me).

### mutant

Задача на исследование защиты от XSS. Нужно проверить, как приложение
обрабатывает пользовательский HTML, и разобраться, почему самодельная
фильтрация не заменяет безопасную обработку вывода. Материалы находятся в
[`Tasks/mutant`](Tasks/mutant).

> В папках `solve/` находятся решения с раскрытием ответа. Не открывайте их до
> самостоятельной попытки решения.

## Получение и обновление задач через Git

Для первой загрузки выполните команды из каталога `lessons/08-real`:

```bash
git clone --filter=blob:none --sparse https://github.com/DownUnderCTF/Challenges_2025_Public.git ductf-2025
cd ductf-2025
git sparse-checkout set web/mini-me web/mutant
git pull origin main
```

После этого задачи будут лежать в `ductf-2025/web/mini-me` и
`ductf-2025/web/mutant`. Чтобы получить последующие изменения, перейдите в
каталог клона и выполните:

```bash
cd lessons/08-real/ductf-2025
git pull origin main
```

Локальные копии для занятия находятся в `Tasks/mini_me` и `Tasks/mutant`.
Имена отличаются только заменой дефиса на подчёркивание для единообразия
структуры репозитория.
