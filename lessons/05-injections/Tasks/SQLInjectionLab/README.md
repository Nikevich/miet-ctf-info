# Решение SQLInjectionLab

## 1. Запуск

Учебное приложение опубликовано в Docker Hub. Загрузите образ:

```bash
sudo docker pull nshkilevich/sqlinjection-lab:latest
```

Затем запустите контейнер. Порт привязан к `127.0.0.1`, поэтому приложение доступно только на локальном компьютере:

```bash
sudo docker run -d \
  --name sqlinjection-lab \
  -p 127.0.0.1:8081:8080 \
  nshkilevich/sqlinjection-lab:latest
```

## 2. Обход формы входа

В форме укажите:

| Поле | Значение |
|---|---|
| Логин | `admin` |
| Пароль | `' OR '1'='1' -- ` |

В конце значения пароля после `--` должен быть пробел.

И мы попадаем под пользователем student. БД ищет все записи пользователя, которые удовлетворяет условию, в нашем случае это все записи. Для обработки код приложения берет первую записть пользователя, который является student. Обойти можно "сократив условие", убрав из обработки password. Для этого в поле логигна необходимо ввести `admin --`, а в поле пароля любое значение.

В форме укажите:

| Поле | Значение |
|---|---|
| Логин | `admin' --` |
| Пароль | `123` |

## 3. Почему вход успешен

Приложение формирует запрос строковой подстановкой:

```sql
SELECT id, login, display_name, private_note
FROM users
WHERE login = 'admin' -- AND password = '123'
```

Найдется запись с логином admin, пароль находится после знака комментария и он не учитывается. Значение 123 необходимо так как поле пароля обязательно для заполнения и без этого запрос на сервер не отправится.
