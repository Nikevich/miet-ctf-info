# Задание 4. Nano и встроенная справка

## Цель

Научиться пользоваться руководством `man` и редактировать текстовый файл в `nano`.

## Выполнение

1. Откройте руководство по команде `ls` командой `man ls`.
2. Найдите в руководстве назначение опций `-a` и `-l`; выйдите из просмотра клавишей `q`.
3. Откройте в редакторе `nano` файл `~/ctf-practice/lesson-1/notes.txt`.
4. Запишите в файл:
   - своё имя или никнейм;
   - значение опций `ls -a` и `ls -l`;
   - две команды, которые были полезны на занятии.
5. Сохраните изменения и выйдите из `nano`.
6. Проверьте содержимое файла командой `cat`.

## Результат

Предъявите содержимое `notes.txt` и устно объясните различие между аргументом команды и её опцией.
