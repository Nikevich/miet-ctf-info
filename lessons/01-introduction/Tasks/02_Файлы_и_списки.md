# Задание 2. Файлы и списки

## Цель

Научиться создавать файлы и просматривать содержимое каталогов с опциями `ls`.

## Выполнение

Работайте внутри каталога `~/ctf-practice/lesson-1`.

1. Создайте файлы `flag.txt`, `notes.txt` и скрытый файл `.hint`.
2. Создайте каталог `evidence`.
3. Выведите обычный список содержимого каталога.
4. Выведите список, включающий скрытые файлы.
5. Выведите подробный список содержимого с правами доступа и размерами.
6. Скопируйте `notes.txt` в каталог `evidence`, затем переименуйте копию в `report.txt`.

## Результат

Приложите вывод команды, в котором видны файлы `flag.txt`, `notes.txt`, `.hint`, каталог `evidence` и файл `evidence/report.txt`.
