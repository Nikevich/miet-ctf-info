# Задания по стеганографии

## Важно

Все файлы для выполнения заданий находятся в архиве:

```text
les-3.zip
```

Распакуйте архив в отдельную директорию и выполняйте задания только с файлами из него. Формат флага:

```text
CTF{...}
```

Задания объединены в пары: одно задание выполняется на занятии, похожее задание остаётся для домашней работы.

## 1. Последний кадр

**Файл:** `01.jpg`  

Фотограф передал снимок с мероприятия и утверждает, что вся полезная информация уже находится в файле.

## 2. Служебная заметка

**Файл:** `02.pdf`  

В PDF нет явной подсказки на странице, но автор просит «не забыть посмотреть свойства документа». Нужно проверить свойства PDF и найти флаг.

## 3. Открытка с сюрпризом

**Файл:** `03.png`  

Изображение выглядит как обычная открытка. Нужно проверить, не содержит ли файл дополнительные данные после формального конца PNG.

## 4. Звук с хвостом

**Файл:** `04.wav`  

Аудиофайл воспроизводится нормально, но его размер выглядит необычно большим для короткой записи. Нужно проверить файл на наличие дополнительных вложенных данных.

## 5. Фотография без пароля

**Файл:** `05.jpg`  

Автор утверждает, что «ничего дополнительно не запирал». 

## 6. Подсказка к снимку

**Файл:** `06.jpg`  

Фотография сопровождается подсказкой: «Вспомни место, где был сделан снимок». В описании задания указано, что пароль — одно слово, без пробелов, строчными буквами. Нужно найти подсказку, подобрать парольную фразу и извлечь флаг.
