# Материалы занятий

Материалы организуются по номеру занятия:

```text
lessons/
  01-introduction/
    ...
  02-crypto/
    ...
```

## 01. Введение

- **Лекция:** что такое CTF, форматы соревнований (Jeopardy, Attack–Defense), основные категории задач, правила и этика участника.
- **Практика:** установка VirtualBox и Kali Linux как виртуальной машины по [инструкции](../resources/kali%20linux/%D0%A3%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0%20VirtualBox.docx); знакомство с терминалом и файловой системой: `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`.
- **Осваиваем:** подготовку рабочей среды, навигацию по каталогам и базовые операции с файлами.
