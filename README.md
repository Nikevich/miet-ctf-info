# MIET CTF Info

Открытый информационный репозиторий команды/сообщества МИЭТ CTF. Здесь
собраны сведения о соревнованиях, writeup’ы, полезные материалы и конспекты
занятий.

## Разделы

- [`competitions/`](competitions/) — карточки прошедших и будущих CTF;
- [`writeups/`](writeups/) — разборы заданий и решений;
- [`resources/`](resources/) — ссылки на платформы, инструменты и учебные материалы;
- [`lessons/`](lessons/) — материалы и заметки по занятиям.

## Как добавить материал

1. Создайте ветку с понятным названием.
2. Не публикуйте флаги действующих соревнований, приватные ключи, пароли и
   персональные данные.
3. Откройте Pull Request с кратким описанием изменений и ссылками на источники.

## Лицензирование

Автор указывает лицензию и источник для каждого добавляемого материала. Если
условия не указаны, текст предназначен только для внутреннего учебного
использования сообщества.
